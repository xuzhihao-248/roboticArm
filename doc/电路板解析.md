## 一、总览

驱动板（MotorDriver-42）是一块**完整的步进电机闭环驱动器**，每块板独立控制一个电机，6 个电机通过 CAN 总线菊花链串联。

| 组件 | 型号 | 作用 |
|------|------|------|
| MCU | **STM32F103CBT6** | Cortex-M3，电机控制算法 + CAN 通信 |
| 电机驱动 | **TB67H450**（东芝） | 双 H 桥，驱动两相步进电机 |
| 编码器 | **MT6816**（MagnTek） | 14-bit 磁编码器，SPI 接口，位置反馈 |
| CAN 收发器 | **TJA1051T/3** | CAN 2.0 差分信号收发 |
| 电源 | **AMS1117-3.3** + **AMS1117-5.0** | 3.3V（供 MCU）+ 5V（供驱动） |
| 状态灯 | 2× **WS2812B** RGB LED | 可编程指示灯（通信/错误状态） |
| 晶振 | 8MHz HSE | 外部高速时钟 |

## 四、CAN 总线拓扑

```
PC ←USB→ Controller（STM32F4 主控）
                │
            CAN 总线（菊花链）
                │
    ┌──┬──┬──┬──┬──┬──┐
   MD1 MD2 MD3 MD4 MD5 MD6   ← 每块 MotorDriver-42 板
   ID=1 ID=2 ID=3 ID=4 ID=5 ID=6
```

- 物理层：CAN 2.0，TJA1051T/3 收发器
- 每块驱动板有唯一 CAN ID（1~6）
- Controller 转发 PC 指令 → 各驱动板本地闭环控制
- 也可跳过 Controller，PC 通过 USB-CAN 适配器直接发 CAN 指令

## 五、使用方式

### 5.1 打样 PCB

1. 将 `my/HardWarePCB/MotorDriver-42/Gerber/` 目录打包为 zip
2. 上传到嘉立创（jlc.com）→ 下单 PCB 打样
3. 5 片约 ¥5~20，5~7 天到货

### 5.2 焊接

1. 打开 `my/HardWarePCB/MotorDriver-42/Motor-42.pdf` 查看原理图
2. 按原理图中的器件型号采购 BOM
3. 焊接顺序建议：电源（AMS1117）→ MCU（STM32F103）→ CAN（TJA1051T）→ 驱动（TB67H450）→ 连接器

### 5.3 烧录固件

**方式一：直接烧 HEX（最快）**

`raw/dummy/.../Firmware/_Released HEX/Ctrl-Step-Driver-STM32F1-fw.hex`
用 ST-Link 连接 J4（SWD 接口），通过 STM32CubeProgrammer 烧录。

**方式二：自行编译**

用 CLion / STM32CubeIDE 打开 `Firmware/Ctrl-Step-Driver-STM32F1-fw/` 工程，编译后烧录。

### 5.4 上位机调试

- **CLI-Tool**：Python 命令行，通过 USB（Fibre 协议）与 Controller 通信
- **DummyStudio**：Unity 桌面应用，图形化控制界面

## 六、与本项目的关系

```
MoveIt2 规划 → USB-CAN → Controller 主控板 → CAN 总线 → 6× MotorDriver-42 → 6 个步进电机
```

- Controller 板接收上位机指令，通过 CAN 分发给各驱动板
- 每块驱动板运行 FOC 闭环控制，本地完成位置/速度/电流控制
- 跳过 Controller：PC 通过 USB-CAN 适配器直接发 CAN 指令给驱动板
