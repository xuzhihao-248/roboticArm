> 配合阅读：`raw/dummy/AI项目解读/` 下 00-03 号文档

---

## 整体策略

```
第一阶段（桌面调试）：Controller + 驱动板 ×6 + 电机 ×6
   → 全部在桌面上用杜邦线连接
   → 烧录固件、配置CAN总线
   → 电脑通过CLI工具控制6个电机转动
   → 电子系统全部调通 ✅

第二阶段（机械装配）：减速器 + CNC结构件 + 装配
   → 电子已经没问题了，专心搞机械
   → 装好直接联调，不用边装边排查电子故障
```

**好处**：电子问题在桌面上排查只需要万用表和 PC，装进结构之后排查需要把整条臂拆开。

### 2.1 打样策略

| 板子 | 数量 | 方案 | Gerber 状态 |
|------|------|------|------------|
| MotorDriver-42 | 6 块 | 裸板，自己焊 | ✅ 已有 Gerber，直接上传 |
| MotorDriver-20 | 1 块 | 裸板，自己焊 | ❌ 需导出 |
| Controller | 1 块 | **SMT 贴片**，嘉立创焊好寄回 | ❌ 需导出 Gerber + BOM + CPL |
| HandModule | 1 块 | 裸板，自己焊 | ❌ 需导出 |
| LED Ring | 1 块 | 裸板，自己焊 | ❌ 需导出 |
| ~~Dangle~~ | - | 不做 | - |

### 2.2 第一步：上传 MotorDriver-42（现在就可以做）

1. 打开 `1.Hardware/MotorDriver-42/Gerber/`
2. 把目录下**所有文件**打包成 `.zip`
3. 嘉立创 → PCB 在线下单 → 上传 zip → 系统自动识别 4 层板
4. 确认参数：

| 参数 | 选择 |
|------|------|
| 板层 | 4 层板 |
| 板厚 | 1.6mm |
| 阻焊颜色 | 绿色 |
| 字符颜色 | 白色 |
| 表面处理 | 有铅喷锡 HASL |
| 数量 | 6 片 |

5. 提交付款（预计 50-80 元，3-5 个工作日 + 快递）

### 2.3 第二步：处理其他 4 块板子

原项目用 Altium Designer 画的，你没有 AD。两条路：

| 方案 | 操作 | 费用 | 时效 |
|------|------|------|------|
| **A（推荐）** | 淘宝搜 "Altium Designer PcbDoc 转 Gerber" | 20-30 元/个文件 | 1-2 天 |
| B | 自己装 AD 试用版导出 | 免费 | 半天学习 |

> 需要代导出的板子：Controller、MotorDriver-20、HandModule、LED Ring（共 4 个板子，约 80-120 元）
>
> **特别交代**：Controller 板除了 Gerber，还需要导出 **BOM（物料清单）** 和 **CPL（贴片坐标）**，做 SMT 用。

### 2.4 第三步：下单其他板子 + Controller SMT

拿到 Gerber 后：
- **MotorDriver-20 / HandModule / LED Ring**：同 2.2 步骤，裸板下单
- **Controller**：除了 Gerber，还要上传 BOM + CPL，选 "SMT 贴片" 服务。嘉立创会自动匹配可贴元件，缺的他们会通知你。

> Controller SMT 费用估算：贴片费 80-150 元 + 元件费另算

## 4. 手工焊接

> 详细教程：`raw/dummy/AI项目解读/02-SMD手工焊接指南.md`

### 4.1 练手（3-4 天）

1. 淘宝 "SMD 焊接练习板"（约 10 元）
2. B 站搜 "SMD 焊接入门" "LQFP 拖焊" 看 3 个视频
3. 练 0603 电阻电容 → 练 SOP-8 → 练 LQFP-48
4. 直到拖焊 LQFP-48 能一次成功不连锡

### 4.2 实战焊接

先焊 MotorDriver-42（6 块容错）→ Controller 做了 SMT 不用焊 → 再焊其他小模块板。

单板焊接顺序（按元件高度从低到高）：

```
1. 0603/0805 电阻电容
2. SOT-23 三极管/稳压器
3. SOP-8 CAN 收发器
4. LQFP-48 STM32F103     ← 最难的，用拖焊法 + 足量助焊剂
5. QFN 驱动芯片（如有）    ← 需要热风枪
6. 电解电容/直插元件
7. 排针排母/接线端子
```

### 4.3 通电前必查

```
万用表通断挡逐项测：
□ 电源正负极 → 不能短路
□ 3.3V 对地 → 不能短路
□ MCU 的 VDD-GND → 不能短路
□ 每个电解电容两端 → 不能短路

蜂鸣器响 = 短路，不要通电，排查连锡/锡珠/元件放反
```

## 5. 桌面调试：电机转起来

> 这是整个一期最关键的阶段。目标：在桌面上让 Controller + 驱动板 + 电机通过 CAN 总线通信，电脑 CLI 工具能控制电机转动。

### 5.1 桌面接线

用杜邦线在桌面临时连接（不用走线槽，不用装结构）：

```
24V 电源 ──→ Controller
               ├── CAN_H ──→ Motor-1 CAN_H ──→ Motor-2 CAN_H ──→ ...
               ├── CAN_L ──→ Motor-1 CAN_L ──→ Motor-2 CAN_L ──→ ...
               ├── VCC ────→ 各驱动板供电
               └── GND ────→ 各驱动板共地

              CAN 总线两端各一个 120Ω 终端电阻
```

### 5.2 烧录驱动板固件

先只烧 1 块 MotorDriver-42 做验证，跑通了再批处理其余 5 块。

**每块板的流程**：

1. ST-Link 接驱动板 SWD 口：**SWDIO、SWCLK、GND、3.3V** 四条线
2. 打开 STM32 ST-LINK Utility
3. 烧录 `2.Firmware/_Released HEX/Ctrl-Step-Driver-STM32F1-fw.hex`
4. 接 24V 电源，首次上电：电机会轻微抖动（编码器自动校准，正常）
5. 如果校准失败：**同时按住按键 1 + 按键 2 再上电**，强制重新校准
6. 按按键 1 → 进入闭环模式（LED 指示灯变化确认）

**按键功能**：

| 操作 | 功能 |
|------|------|
| 短按按键 1 | 使能闭环 / 取消闭环 |
| 长按按键 1 | 重启 |
| 短按按键 2 | 清除堵转保护 |
| 长按按键 2 | 目标值归零 |

### 5.3 烧录核心板固件

1. ST-Link 接 Controller 板 SWD 口
2. 烧录核心固件（从 `2.Firmware/Core-STM32F4-fw/` 编译，或直接用已编译的 hex）
3. 上电后通过串口配置：
   - 各电机 CAN ID：设为 1-6（不要重复）
   - 各关节减速比：**桌面调试阶段先设为 1:1**（无减速器）
   - 关节运动限制：先设大一点

### 5.4 CAN 总线调试要点

```powershell
# 用 USB-CAN 工具监听总线，确认每个电机 ID 都能收到数据
```

| 检查项 | 标准 |
|--------|------|
| 终端电阻 | 总线两端各 120Ω（测量 CAN_H 与 CAN_L 之间约 60Ω） |
| 波特率 | 全部 1Mbps |
| 接线 | CAN_H 对 CAN_H，CAN_L 对 CAN_L |
| CAN ID | 6 个 ID 不冲突 |

### 5.5 CLI 工具控制电机

```powershell
cd 3.Software/CLI-Tool/
pip install pyserial

python run_shell.py
# 进入交互 Shell 后发送单关节运动指令
```

**桌面调试里程碑**：电脑通过 CLI 发送指令 → 6 个电机各自转动 → 速度/方向可控 ✅

> 到这一步，电子系统就完全跑通了。后续机械部分出问题，可以确定不是电子的锅。

## 6. 减速器选型：测量 STEP 模型

> 电子调通后再搞，时间不浪费。测量完先买 1 个样品确认匹配。

### 6.1 打开模型

FreeCAD（免费，前面已安装）→ 打开 `4.Model/Dummy v164.step`

### 6.2 每个关节需要测量的 4 个尺寸

```
┌─────────────────┐
│    减速器        │
│  ← A → 输入孔径  │  A = 电机轴直径（42 步进常见 5mm 或 6.35mm）
│  ← D → 法兰外径  │  D = 与关节结构安装孔匹配
│  ← H → 总高度    │  H = 关节空间高度限制
│  输出接口类型     │  轴输出还是法兰输出？尺寸？
└─────────────────┘
```

FreeCAD 操作：放大关节区域 → 工具栏 Measure → 测量 → 记录。

| 关节 | 输入孔径 A | 法兰直径 D | 总高度 H | 输出接口 | 推荐型号 |
|------|-----------|-----------|---------|---------|---------|
| J1 底座回转 | ___ mm | ___ mm | ___ mm | ___ | ___ |
| J2 肩部 | ___ mm | ___ mm | ___ mm | ___ | ___ |
| J3 肘部 | ___ mm | ___ mm | ___ mm | ___ | ___ |
| J4 腕部 | ___ mm | ___ mm | ___ mm | ___ | ___ |
| J5 腕部 | ___ mm | ___ mm | ___ mm | ___ | ___ |
| J6 腕部末端 | ___ mm | ___ mm | ___ mm | ___ | ___ |

### 6.3 根据测量结果选型号

**方案：走便宜路线，1688 或淘宝找国产谐波减速器。**

| 型号 | 外径约 | 额定扭矩约 | 适合关节 | 1688 参考价 |
|------|--------|-----------|---------|------------|
| CSF-11 / 14 小型号 | φ44-54mm | 2-4 N·m | J4/J5/J6 腕部 | 200-280 元 |
| CSF-17 中型号 | φ66mm | 5-8 N·m | J1/J2/J3 底部 | 250-350 元 |

**选择原则**：
- 减速比统一 **30:1**（不改运动学代码）
- 扭矩需求：J1/J2 最大 → J3 中等 → J4/J5/J6 最小
- **先买 1 个 J1 用的型号做样品**，收到实物确认接口匹配再买齐 6 个

### 6.4 采购渠道

| 渠道 | 关键词 | 说明 |
|------|--------|------|
| 1688 | "谐波减速器 CSF-14-30" | 批发价，直接找厂家 |
| 淘宝 | "国产谐波减速器 30速比" | 零售价但售后方便 |
| 品牌 | 来福谐波 / 大族传动 | 比绿的谐波便宜一档 |

> **6 个预算约 1200-2000 元**

## 8. 机械装配

> 桌面调试通过 + 减速器到齐 + CNC 件到齐 → 开始装配。

### 8.1 装配物料清单

- [ ] CNC 加工件（所有关节结构）
- [ ] 谐波减速器 ×6（J1-J6）
- [ ] 42 步进电机 ×6
- [ ] 20 步进电机 ×1（夹爪）
- [ ] M2/M3 不锈钢内六角螺丝螺母
- [ ] CAN 总线线缆（4 芯双绞屏蔽线）
- [ ] JST 连接器 XH2.54

### 8.2 装配顺序

```
1. 所有 CNC 件去毛刺、检查螺纹孔
2. J1 底座：结构件 → 减速器 → 电机 → 螺丝固定
3. J2 → J3 → J4 → J5 → J6 依次向上装配
4. 每个关节装好后手动转动确认顺滑
5. CAN 总线布线（4 线串联全部关节）
6. 安装夹爪 + LED 灯环
```
