# Dummy 机械臂二次开发需求文档

> 基于开源项目 [Dummy](https://github.com/peng-zhihui/Dummy) 进行复刻与二次开发
> 原版作者：稚晖君 | 文档版本：v1.0 | 日期：2026/05/23

---

## 一、项目概述

### 1.1 项目背景

Dummy 是一台 6 轴串联机械臂，采用 STM32F4 + STM32F1 双 MCU 架构，CAN 总线通信，42 步进电机 + 谐波减速器驱动，上位机基于 Unity3D。

### 1.2 项目目标

| 阶段 | 目标 | 产出 |
|------|------|------|
| **一期** | 复刻原版 Dummy，机械臂跑起来 | 一台可用的 6 轴机械臂 |
| **二期** | 理解核心原理，具备修改能力 | 运动学/控制算法可自行调整 |
| **三期** | 加装视觉抓取功能 | 能识别并抓取指定物体 |
| **四期** | 移动底盘 + SLAM 导航（根据难度决策） | 移动机械臂自主导航 |
| **五期** | VLA 自然语言操控 | 语言指令 → 机械臂动作 |

### 1.3 预算

- 硬件预算：5000 元以内（不含 CNC 加工）
- CNC 加工：单独询价，预计 2000-4000 元

## 二、一期：复刻原版 Dummy

### 2.1 需求描述

严格按照原版设计，完成一台完整的 6 轴机械臂，能够通过 CLI 工具和 DummyStudio 进行控制。

### 2.2 功能需求

| ID | 功能 | 验收标准 |
|----|------|---------|
| F1.1 | 6 轴关节运动 | 每个关节可独立响应指令，角度误差 < 0.1° |
| F1.2 | 正逆运动学 | 给末端位姿 → 各关节到位姿，给角度 → 末端到位姿 |
| F1.3 | 轨迹规划 | MoveJ 指令执行平滑，梯形加减速无卡顿 |
| F1.4 | CAN 总线通信 | 6 个电机同步广播，响应延迟 < 5ms |
| F1.5 | CLI 控制 | Python CLI 工具可连接、发送指令、读取状态 |
| F1.6 | 图形化控制 | DummyStudio 可连接、拖动控制、轨迹仿真 |
| F1.7 | 零点归位 | 上电后自动完成零点校准 |

### 2.3 硬件清单

| 类别 | 内容 | 数量 |
|------|------|------|
| 机械结构 | 铝 CNC 加工件 + 阳极氧化 | 1 套 |
| 减速器 | 国产谐波减速器 CSF-14/17-30 | 6 个 |
| 电机 | 42 步进电机（双轴） | 6 个 |
| 电机 | 20 步进电机（夹爪） | 1 个 |
| 主控板 | Controller（STM32F405） | 1 块 |
| 驱动板 | MotorDriver-42（STM32F103） | 6 块 |
| 驱动板 | MotorDriver-20 | 1 块 |
| 模块板 | HandModule / LED Ring | 各 1 块 |
| 电源 | 24V 10-15A 开关电源 | 1 个 |
| 工具 | ST-Link V2 / USB-CAN 调试器 | 各 1 个 |

### 2.4 软件环境

| 软件 | 用途 |
|------|------|
| STM32CubeIDE / Keil MDK | 固件编译 |
| STM32 ST-LINK Utility | 固件烧录 |
| Python 3.7+ | CLI 调试工具 |
| Unity3D | DummyStudio 上位机 |
| Altium Designer（或淘宝代导出） | Gerber/BOM 导出 |

## 三、二期：核心原理掌握

### 3.1 需求描述

深入理解每个模块的原理，能够修改运动学参数、调整控制算法。

### 3.2 学习目标

| 模块 | 内容 | 产出 |
|------|------|------|
| 运动学 | DH 参数、正逆解推导 | Python 版正逆解实现 |
| 轨迹规划 | 梯形加减速、多关节同步 | 独立实现轨迹插值 |
| 电机控制 | FOC、PID 三环、编码器 | 修改控制参数并验证 |
| CAN 协议 | 帧格式、广播同步 | 自定义一个 CAN 指令 |
| FreeRTOS | 任务调度、队列通信 | 在固件中新增一个 Task |

---

## 四、三期：视觉抓取系统

### 4.1 需求描述

加装深度相机，实现目标检测 → 3D 定位 → 抓取规划 → 执行抓取的完整流程。

### 4.2 功能需求

| ID | 功能 | 技术方案 | 验收标准 |
|----|------|---------|---------|
| F3.1 | 手眼标定 | Eye-to-hand 标定 | 标定误差 < 2mm |
| F3.2 | 物体检测 | YOLOv8 或 OpenCV | 识别 3 种以上物体，准确率 > 90% |
| F3.3 | 3D 位姿估计 | 点云分割 + ICP | 位姿误差 < 5mm |
| F3.4 | 抓取规划 | 几何分析 + 碰撞检测 | 单物体抓取成功率 > 80% |
| F3.5 | 视觉伺服 | 闭环视觉反馈 | 末端逼近过程中实时修正 |

### 4.3 硬件增加

| 硬件 | 推荐型号 | 预估价格 |
|------|---------|---------|
| RGB-D 深度相机 | Intel RealSense D435 / 奥比中光 DaBai DCW | 1000-2000 元 |
| 相机支架 | 3D 打印 | 自行设计 |

## 六、五期：VLA 自然语言操控

### 6.1 需求描述

通过自然语言（语音/文字）控制机械臂完成复杂任务。

### 6.2 功能需求

| ID | 功能 | 技术方案 |
|----|------|---------|
| F5.1 | 语音识别 | Whisper 语音转文字 |
| F5.2 | 任务理解 | LLM 提取意图和参数 |
| F5.3 | 任务规划 | LLM + PDDL 分解子任务 |
| F5.4 | 技能执行 | Python API 封装的运动原语 |
| F5.5 | 闭环纠错 | 视觉反馈 + 任务重规划 |

### 6.3 技术栈

```
用户语音 → Whisper（语音→文字）
          ↓
LLM（Qwen / GPT-4o）→ 意图解析 + 任务分解
          ↓
Python 控制 API → 每个子任务对应可执行函数
          ↓
机械臂执行 → 视觉反馈 → 确认 / 重试
```

## 八、风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| CNC 加工精度不足 | 关节卡顿 | 加工前确认公差 ±0.05mm，找有机械臂经验加工商 |
| 谐波减速器批次差异大 | 安装干涉 | 先买 1 个样品确认接口匹配 |
| STM32 翻新/假货 | 固件不稳定 | 从授权代理商购买（立创商城、得捷、Mouser） |
| LQFP/QFN 焊接失败 | PCB 报废 | Controller 板做 SMT，驱动板先练手 |
| 减速比与原版不同 | 运动学代码需重调 | 统一全部用 30:1，与作者保持一致 |
| Clash 代理干扰 GitHub | 拉不下代码 | 走 HTTPS + 配置代理 |
