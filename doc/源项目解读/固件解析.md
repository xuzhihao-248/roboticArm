## 一、总览

Firmware 目录下有**两个独立固件工程**，分别对应两块电路板：

| 固件 | 目标芯片 | 对应电路板 | 作用 |
|------|---------|-----------|------|
| **Ctrl-Step-Driver-STM32F1-fw** | STM32F103CBT6 | MotorDriver-42 | 单电机闭环驱动（每块板一个） |
| **Core-STM32F4-fw** | STM32F405RGTx | Controller 主控板 | 6 轴运动协调 + USB/UART/CAN 通信 |

预编译 HEX：`_Released HEX/Ctrl-Step-Driver-STM32F1-fw.hex`（驱动板固件，可直接烧录）

### 3.3 FreeRTOS 线程

文件：`UserApp/main.cpp`

| 线程 | 优先级 | 频率 | 作用 |
|------|--------|------|------|
| **ControlLoopFixUpdate** | Realtime | 200Hz（Timer7） | 发送控制指令 + 更新关节状态 |
| **ControlLoopUpdate** | Normal | 阻塞等待 | 解析命令队列 |
| **OledTask** | Normal | 持续运行 | 更新 OLED 显示（IMU、关节角度、位姿） |

**控制循环流程（200Hz）：**

```
Timer7 中断 → 唤醒 ControlLoopFixUpdate 线程
    ├── 如果已使能：
    │   ├── SEQUENTIAL / INTERRUPTABLE / TRAJECTORY 模式：
    │   │   ├── MoveJoints(targetJoints) → 通过 CAN 发送目标角度给各驱动板
    │   │   └── UpdateJointPose6D() → 正运动学计算当前位姿
    │   └── MOTOR_TUNING 模式：
    │       └── tuningHelper.Tick() → 调试用正弦波运动
    └── 如果未使能：
        ├── UpdateJointAngles() → 读取各关节当前角度
        └── UpdateJointPose6D() → 正运动学
```

> **关键代码位置：** `UserApp/main.cpp` :17-48

## 四、CAN 协议详解

### 4.1 帧格式

CAN ID 编码：`StdId = (NodeID << 7) | Command`

| 字段 | 位 | 说明 |
|------|-----|------|
| NodeID | [10:7] | 驱动板 ID（1~6），0 表示广播 |
| Command | [6:0] | 命令码（0x00~0x7F） |

### 4.2 命令表

**控制命令（0x00~0x0F）— 不写入 EEPROM：**

| 命令 | 数据 | 说明 |
|------|------|------|
| 0x01 | uint32: 1=enable, 0=disable | 使能/失能电机 |
| 0x02 | — | 触发编码器校准 |
| 0x03 | float: current(A) | 设置电流目标 |
| 0x04 | float: velocity(r/s) | 设置速度目标 |
| 0x05 | float: position(r) + uint8: needAck | 设置位置目标 |
| 0x06 | float: position(r) + float: time(s) | 位置+时间 |
| 0x07 | float: position(r) + float: vel_limit(r/s) | 位置+速度限制 |

**配置命令（0x10~0x1F）— 写入 EEPROM：**

| 命令 | 数据 | 说明 |
|------|------|------|
| 0x11 | uint32: nodeID | 设置 CAN ID |
| 0x12 | float: current(A) | 设置电流限制 |
| 0x13 | float: velocity(r/s) | 设置速度限制 |
| 0x14 | float: acceleration(r/s²) | 设置加速度 |
| 0x15 | — | 当前位置设为零位 |
| 0x16 | uint32: 1=enable | 上电自动使能 |
| 0x17 | int32: kp | DCE Kp |
| 0x18 | int32: kv | DCE Kv |
| 0x19 | int32: ki | DCE Ki |
| 0x1A | int32: kd | DCE Kd |
| 0x1B | uint32: 1=enable | 堵转保护 |

**查询命令（0x20~0x2F）— 驱动板返回数据：**

| 命令 | 返回数据 | 说明 |
|------|---------|------|
| 0x21 | float: current(A) + uint8: state | 读取电流 |
| 0x22 | float: velocity(r/s) + uint8: state | 读取速度 |
| 0x23 | float: position(r) + uint8: state | 读取位置 |
| 0x24 | int32: offset | 读取零位偏移 |

**系统命令：**

| 命令 | 说明 |
|------|------|
| 0x7E | 擦除 EEPROM 配置 |
| 0x7F | 重启驱动板 |

> **关键代码位置：** `UserApp/protocols/interface_can.cpp` :20-238

### 4.3 CAN 回调（主控板侧）

主控板收到驱动板的 0x23 应答后：

```cpp
// can_protocol.cpp :28-29
case 0x23:
    dummy.motorJ[id]->UpdateAngleCallback(*(float*)(data), data[4]);
    break;
```

## 五、完整通信链路

```
PC（CLI-Tool / DummyStudio）
    │ USB（Fibre 协议，Endpoint RPC）
    ↓
Controller（STM32F4，FreeRTOS）
    │ DummyRobot::MoveJoints() → CtrlStepMotor::SetPositionSetPoint()
    ↓
CAN 总线（StdId = NodeID<<7 | 0x05）
    ↓
MotorDriver × 6（STM32F1）
    │ OnCanCmd(0x05) → motor.controller->SetPositionSetPoint()
    ↓
TB67H450 → 步进电机
    ↑
MT6816 编码器反馈 → motor.Tick20kHz() 闭环控制
```
