## 一、总览

Software 目录下有两个工具：

| 工具 | 类型 | 作用 |
|------|------|------|
| **CLI-Tool** | Python 命令行 | 调试、配置驱动板参数，支持交互式 Shell |
| **DummyStudio** | Unity 桌面应用 | 图形化控制界面，可视化操作 |

两个工具都通过 **Fibre 协议** 与 Controller 主控板（STM32F4）通信，Controller 再通过 CAN 总线转发指令给各驱动板。

```
PC（CLI-Tool / DummyStudio）
    │ USB（Fibre 协议）
    ↓
Controller（STM32F4）
    │ CAN 总线
    ↓
MotorDriver × 6（STM32F1 + TB67H450）
```

### 2.2 Fibre 通信协议

Fibre 是一套**轻量级 RPC 框架**（源自 ODrive 项目），用于 PC 与嵌入式设备通信。

**协议参数：**

| 参数 | 值 | 来源 |
|------|-----|------|
| 同步字节 | `0xAA` | `fibre/protocol.py` :21 |
| CRC8 多项式 | `0x37` | `fibre/protocol.py` :26 |
| CRC16 多项式 | `0x3d65` | `fibre/protocol.py` :27 |
| 最大包大小 | 128 字节 | `fibre/protocol.py` :29 |
| 协议版本 | 1 | `fibre/protocol.py` :24 |

**数据包格式：**

```
┌────────┬────────┬──────────┬─────────┬───────┐
│ SYNC   │ CRC8   │ Payload  │ CRC16   │       │
│ 0xAA   │ 1 byte │ ≤128 B   │ 2 bytes │       │
└────────┴────────┴──────────┴─────────┴───────┘
```

**支持的传输层：**

| 传输层 | 文件 | 默认 | 说明 |
|--------|------|------|------|
| USB Bulk | `usbbulk_transport.py` | ✅ | 通过 pyusb 访问 USB 设备 |
| Serial | `serial_transport.py` | — | 串口（/dev/ttyUSB0 等） |
| TCP | `tcp_transport.py` | — | TCP 网络连接 |
| UDP | `udp_transport.py` | — | UDP 网络连接 |

**USB 设备识别（VID:PID）：**

```python
# usbbulk_transport.py :15-18
WELL_KNOWN_VID_PID_PAIRS = [
    (0x1209, 0x0D31),
    (0x1209, 0x0D32),
    (0x1209, 0x0D33)
]
```

### 2.3 设备发现流程

`fibre/discovery.py` 中的 `find_all()` 函数：

```
1. 按 path 参数选择传输层（默认 "usb"）
2. 启动发现线程，扫描匹配的设备
3. 连接后读取 Endpoint 0（设备返回 JSON 接口定义）
4. 解析 JSON，创建 RemoteObject 远程对象代理
5. 回调通知上层：设备已连接
```

**关键代码位置：**

| 步骤 | 文件 | 行号 |
|------|------|------|
| 加载传输层 | `fibre/discovery.py` | :18-42 |
| 发现设备 | `fibre/discovery.py` | :47-110（`find_all()`） |
| 读取接口定义 | `fibre/discovery.py` | :68 | `channel.remote_endpoint_read_buffer(0)` |
| 解析 JSON | `fibre/discovery.py` | :82 | `json.loads(json_string)` |
| 创建远程对象 | `fibre/discovery.py` | :87 | `RemoteObject(json_data, ...)` |

### 2.4 远程对象（RPC 调用）

`fibre/remote_object.py` 实现了**远程属性读写**：

```python
# 使用示例（伪代码）
device = ref_tool.find_any()              # 发现设备
device.axis0.encoder.pos_estimate         # 读取编码器位置（远程读）
device.axis0.pos_setpoint = 10000         # 设置目标位置（远程写）
```

原理：Python 对象的属性访问被拦截，转换为 Fibre 协议的 **Endpoint 读写操作**，通过 USB 发送给 Controller，Controller 再通过 CAN 转发给对应驱动板。

### 2.5 交互式 Shell

`ref_tool/shell.py` 启动后：

1. 等待设备连接（USB 扫描）
2. 连接成功后创建 `dummy0` 对象
3. 进入 IPython/Python 交互式 Shell
4. 用户可直接操作 `dummy0` 的属性，如：
   ```python
   dummy0.axis0.encoder.pos_estimate    # 读位置
   dummy0.axis0.pos_setpoint = 10000    # 设位置
   dummy0.axis0.motor.current           # 读电流
   ```

### 2.6 使用方式

**Windows：**

```bash
# 方式一：双击 run.bat
# 方式二：命令行
cd Software/CLI-Tool
python run_shell.py
```

**Linux：**

```bash
cd Software/CLI-Tool
python3 run_shell.py
```

**指定连接方式：**

```bash
python run_shell.py --path usb                    # USB（默认）
python run_shell.py --path serial:/dev/ttyUSB0    # 串口
python run_shell.py --path tcp:192.168.1.100      # TCP
```

**Windows USB 驱动：**

首次使用需运行 `zadig-2.5.exe` 安装 USB 驱动（替换为 libusb-win32 或 WinUSB）。

## 三、DummyStudio

路径：`Software/DummyStudio/`

### 3.1 基本信息

| 项目 | 说明 |
|------|------|
| 类型 | Unity 桌面应用（Mono 运行时） |
| 主程序 | `DummyStudio.exe` |
| 运行时 | `MonoBleedingEdge/`（内嵌 Mono，无需额外安装） |
| 引擎 | `UnityPlayer.dll` |

### 3.2 功能

DummyStudio 是 Dummy-Robot 的**图形化控制软件**，提供：

- 设备连接管理（USB 自动发现）
- 电机位置/速度/电流实时监控
- 电机运动控制（位置指令、速度指令）
- 参数配置（PID、电流限值等）
- 实时数据曲线绘图

### 3.3 使用方式

```bash
# Windows 直接双击
Software/DummyStudio/DummyStudio.exe
```

> 需要先用 zadig 安装 USB 驱动（同 CLI-Tool）。

## 四、CLI-Tool vs DummyStudio 对比

| 对比项 | CLI-Tool | DummyStudio |
|--------|----------|-------------|
| 界面 | 命令行（Python Shell） | 图形化（Unity GUI） |
| 适合场景 | 调试、脚本自动化、批量配置 | 日常使用、可视化监控 |
| 依赖 | Python 3 + pyusb + IPython（可选） | 无依赖（自带运行时） |
| 可编程性 | ✅ 可写 Python 脚本 | ❌ 仅图形操作 |
| 实时绘图 | ✅ liveplotter | ✅ 内置曲线图 |
| 跨平台 | ✅ Windows/Linux/macOS | ✅ Windows（主要） |

## 五、与本项目的关系

本项目（6 轴机械臂）使用 MoveIt2 作为上位机，不直接使用 CLI-Tool 或 DummyStudio。但这两个工具在**调试阶段**非常有用：

| 阶段 | 工具 | 用途 |
|------|------|------|
| 硬件验收 | CLI-Tool | 逐个电机测试，验证 CAN 通信和编码器反馈 |
| 参数调试 | CLI-Tool | 调整 PID 参数、电流限值、速度限制 |
| 运动测试 | DummyStudio | 图形化拖动电机，直观验证运动效果 |
| 故障排查 | CLI-Tool | 读取错误码、电机状态、CAN 通信日志 |
| MoveIt 对接 | 无需这两个工具 | 直接通过 USB-CAN 发 CAN 指令 |
