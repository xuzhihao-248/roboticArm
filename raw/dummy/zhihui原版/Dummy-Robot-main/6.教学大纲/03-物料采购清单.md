### JLC 嘉立创下单步骤

```
步骤1：注册 jlc.com 账号

步骤2：上传 MotorDriver-42 的 Gerber
  → 将 Gerber/ 目录下所有文件压缩成一个 .zip
  → 在嘉立创选"PCB在线下单"
  → 上传 zip，系统会自动识别为 4层板，尺寸约等待解析
  → 按上表确认参数
  → 数量选6
  → 提交订单并付款（预计 4层板 6片约 50-80元）

步骤3（其他板子需要导出 Gerber）：
  → 其他板子（Controller / MotorDriver-20 / HandModule / LED Ring / Dangle）
    需要从 .PcbDoc 导出 Gerber
  → 导出方法见下方"附录A：从 .SchDoc 导出 BOM"的同类操作
  → 如果没有 Altium Designer，去淘宝搜"Altium Designer PcbDoc转Gerber"约20-30元/文件
```

### 是否做 SMT 贴片？

- **Controller 核心板** → 建议做 SMT（只有1块，容错成本高，BGA/QFN元件多）
- **MotorDriver-42 ×6** → 做裸板自己焊（练习焊接+省钱，LQFP-48 熟练后不难）
- **其他板子** → 做裸板自己焊
- SMT 需要额外提供 **BOM 文件** 和 **CPL（坐标）文件**，导出方法见下方

## 附录A：从 .SchDoc / .PcbDoc 导出 BOM 和 Gerber（图文步骤）

> 你需要安装 Altium Designer（以下简称AD）。如果电脑没装、也不想装，可以跳过本节直接去淘宝找人代导出。

### A.1 安装 Altium Designer（如需自行导出）

AD 是收费软件，但可以下载试用版完成导出。搜索 "Altium Designer 下载" 即可。
版本建议：AD20 或更新。文件是本项目用 AD 创建的，新版本都能打开。

### A.2 导出 BOM（物料清单）—— 从原理图 .SchDoc

```
1. 打开 AD，File → Open → 选择 .SchDoc 文件（如 MotorDriver-42 的 Main.SchDoc）
   注意：如果原理图是多页的（MotorDriver-42 有5个 .SchDoc：
       Drive.SchDoc / Interface.SchDoc / MCU.SchDoc / Port.SchDoc / Power.SchDoc）
       需要在 AD 的项目面板中把所有 SchDoc 加入同一个工程后再导出 BOM

2. Reports → Bill of Materials

3. 在弹出的 BOM 窗口中：
   - 可以看到所有元件的列表（Designator / Comment / Footprint / Quantity 等列）
   - 检查"Comment"列是否显示了元件型号（这是你要买的东西）
   - 如果 Comment 是空的或显示不完整，说明原理图缺少元件信息，需要手动补充

4. 导出：
   - 点击左下角 "Export..."
   - 文件格式选 "CSV (*.csv)"
   - 保存到本地

5. CSV 文件可以用 Excel 打开，整理成购物清单：
   - 关键列：Designator（位号）、Comment（型号/值）、Footprint（封装）、Quantity（数量）
   - 相同 Comment 的合并计算总数量
   - 加上 10% 备损量 = 最终购买数量
```

### A.3 导出 CPL（贴片坐标文件）—— 从 PCB .PcbDoc

```
CPL（Component Placement List）告诉贴片机每个元件在板上的位置和角度。

1. 打开 AD，打开 .PcbDoc 文件

2. File → Assembly Outputs → Generates pick and place files

3. 在弹出的窗口中：
   - 格式选 "CSV"
   - 单位选 "Metric"（mm）
   - 点 OK

4. AD 会生成一个 .csv 文件，包含：
   - Designator（位号）
   - Mid X / Mid Y（元件中心坐标）
   - Layer（Top / Bottom）
   - Rotation（旋转角度）

5. 这个 CSV 文件和 BOM 一起上传给嘉立创做 SMT 贴片
```

### A.4 导出 Gerber（制造文件）—— 从 PCB .PcbDoc

```
对于没有现成 Gerber 的板子（Controller / MotorDriver-20 / HandModule 等）：

1. 打开 .PcbDoc 文件

2. File → Fabrication Outputs → Gerber Files
   - General 标签页：单位选 Millimeters，格式选 4:4
   - Layers 标签页：勾选所有使用的层（Plot Layers 全选）
   - 勾选 "Include unconnected mid-layer pads"
   - 点 OK

3. File → Fabrication Outputs → NC Drill Files
   - 单位选 Millimeters，格式选 4:4
   - 点 OK

4. 把生成的 Gerber Output 文件夹内所有文件打包成 zip
   → 这就是可以上传嘉立创的文件
```

## 采购避坑建议

1. **分阶段买，不要一次性下单全部。** 先做PCB打样→确认板子没问题→再买元件→焊好一块驱动板测试通过→再焊全部
2. **STM32芯片谨防假货/翻新货。** 在靠谱的店铺购买，价格过于便宜的要警惕。正品 STM32F103CBT6 约 15-25 元/片
3. **减速器先买1个样品。** 确认机械接口匹配后再买齐，国产谐波有些批次公差较大
4. **电阻电容多买一些。** 0603元件便宜但容易弄丢，多备10-20%不会错
5. **CNC加工前务必确认图纸。** 把STEP模型发给加工商后，让他们出加工图纸给你确认，确保公差标注清楚
