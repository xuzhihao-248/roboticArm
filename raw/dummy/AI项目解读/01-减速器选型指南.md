# 减速器选型指南

> 目标：帮助你独立判断为 Dummy 机械臂的每个关节选择合适的减速器

---

## 一、减速器基础知识

### 为什么机械臂需要减速器？

步进电机直接输出扭矩很小，转速很高。减速器的作用是：

- **放大扭矩**：输出扭矩 = 电机扭矩 × 减速比 × 效率
- **降低转速**：输出转速 = 电机转速 / 减速比
- **提高精度**：减速后每一步的角度更精细

例如：减速比30:1，意味着电机转30圈，关节输出轴转1圈。步进电机1.8°/步，经过30倍减速后关节每步只有 0.06°，精度大幅提升。

### 常见减速器类型对比

| 类型 | 精度 | 背隙 | 体积 | 价格 | 适合场景 |
|------|------|------|------|------|---------|
| **谐波减速器** | 极高 | 几乎为0 | 紧凑 | 贵（300-1000元） | 高精度机械臂 |
| **摆线针轮减速器** | 高 | 极小 | 紧凑 | 中等 | 中型负载 |
| **行星减速器** | 中等 | 小（1-3 arcmin） | 较紧凑 | 便宜（50-200元） | 一般精度场合 |
| **谐波+行星混合** | 高 | 混合 | 中等 | 中 | 预算折中方案 |

### Dummy 原版的方案

原版使用 **谐波减速器**，配合 **42步进电机**。

- 型号类似 Harmonic Drive 的 CSF/CSG 系列
- 减速比约 30:1
- 杯型（Cup type）谐波，轴向更薄

## 二、选型关键参数

### 2.1 减速比

```
减速比 = 电机输出端转速 / 关节输出转速

对于机械臂来说：
- 太小的减速比（<20）→ 扭矩不足，精度不够
- 太大的减速比（>100）→ 关节转得太慢，运动速度不够
- 常用范围：20:1 ~ 50:1
```

**Dummy 项目建议：30:1**（与原版一致，DH参数和运动学不需要大改）

### 2.2 扭矩计算（简略版）

```
关节所需扭矩 ≈ 末端负载重量 × 最大力臂长度 × 安全系数

安全系数一般取 1.5-2.0
力臂长度 ≈ 肘关节到底座的距离（最坏情况）

比如：
- 末端负载 0.5kg（夹爪+物体）
- 水平伸展 0.4m
- 底座关节扭矩 ≈ 0.5 × 10 × 0.4 × 2 = 4 N·m
```

**Dummy 项目中各关节扭矩参考（粗略估算）：**

| 关节位置 | 扭矩需求 | 原因 |
|---------|---------|------|
| J1 底座回转 | 最大 | 需要带动整个机械臂旋转 |
| J2 肩部俯仰 | 最大 | 抵抗重力，臂展最长时力矩最大 |
| J3 肘部俯仰 | 中等 | 力臂较短 |
| J4/J5/J6 腕部 | 小 | 只带动末端和负载 |

**建议：**
- 国产谐波减速器常见额定扭矩约 2-8 N·m（14/17型号），对 Dummy 应足够
- 如果选行星减速器，J1/J2 需要选择扭矩较大型号（25/32 法兰）

### 2.3 尺寸兼容性

**最重要的步骤：打开 `4.Model/Dummy v164.step` 测量！**

需要确认的尺寸：
- 减速器输入轴直径和长度 → 与电机轴匹配
- 减速器输出端的安装法兰尺寸 → 与关节结构件匹配
- 减速器总高度（轴向长度）→ 不能超过关节空间

如果不匹配，有两个解决途径：
1. 设计转接法兰（3D打印或CNC加工）
2. 更换不同品牌/型号的减速器

### 2.4 背隙（Backlash）

| 减速器类型 | 典型背隙 | 对机械臂的影响 |
|-----------|---------|--------------|
| 谐波减速器 | < 30 arcsec（几乎为0） | 可以忽略 |
| 摆线针轮 | < 1 arcmin | 轻微影响重复定位精度 |
| 行星减速器 | 1-3 arcmin | 末端可能有明显晃动 |

**背隙对末端精度的影响：**
```
末端偏差 ≈ 减速器背隙 × 臂展长度 × sin(关节角)

例如：背隙 3 arcmin ≈ 0.05°
臂展 40cm → 末端晃动 ≈ 0.35mm
```

> 注：本项目使用闭环驱动，编码器在电机端，无法补偿减速器背隙。所以背隙尽量选小。

## 三、国产谐波减速器选购指南

### 主要品牌

| 昊志机电 | 较新品牌 | 200-300元 | 1688 |

### 谐波减速器型号解读

国产型号通常仿 Harmonic 命名：

```
CSF-14-30-2UH
│    │  │  └─ 输出端类型（UH=轴输出，GR=法兰输出）
│    │  └──── 减速比（30 → 30:1）
│    └─────── 型号（14 → 外径约 φ54mm，17 → 外径约 φ66mm）
└────────── 杯型（CSF）/ 帽型（CSG）/ 超薄（CSD）
```

**Dummy 项目中可能适合的型号：**
- CSF-14-30（尺寸更小，适合腕部 J4/J5/J6）
- CSF-17-30（扭矩更大，适合肩肘 J2/J3 和底座 J1）

> 以上是推测，请对照 STEP 模型的实际安装空间确认！

### 淘宝/1688 选购 Tips

1. **搜索关键词：** "谐波减速器 CSF-14-30" 或 "国产谐波减速器 30速比"
2. **注意区分新品和拆机件：** 拆机 Harmonic Drive 进口件约 300-600 元，新的国产件 200-500 元
3. **问清楚：** 是否带输入轴套？输出端是什么形式？精度等级？
4. **批量买6个可以跟店家谈价格**

## 四、如果你不选谐波减速器

### 方案 B：行星减速器

| 优势 | 劣势 |
|------|------|
| 价格便宜（50-200元/个） | 背隙较大（1-3 arcmin） |
| 种类多，购买方便 | 体积相对较大 |
| 多级减速可选 | 精度较低 |

**适用型号：** NEMA17 或 NEMA23 精密行星减速器，20:1-50:1

**注意：** 行星减速器需要确认背隙等级。普通级（P1）背隙约 3 arcmin，精密级（P0）背隙约 1 arcmin。

### 方案 C：摆线针轮减速器

作者稚晖君设计了低成本的摆线针轮减速器：
- 开源项目：[CycloidAcuratorNano](https://github.com/peng-zhihui/CycloidAcuratorNano)
- 用 PC/亚克力切割片 + 3D打印外壳
- 成本极低但精度下降

## 五、你需要做的事

1. **打开 STEP 模型，测量每个关节的减速器安装空间**
2. **确认电机轴直径和输出轴连接方式**
3. **根据位置选型号：**
   - J1（底座）：扭矩最大 → CSF-17 或更大
   - J2（肩部）：扭矩大 → CSF-17
   - J3（肘部）：扭矩中等 → CSF-14 或 CSF-17
   - J4/J5/J6（腕部）：扭矩小 → CSF-11 或 CSF-14
4. **统一减速比（建议全部30:1），这样不至于改运动学代码**
5. **联系供应商询价，确认库存**
