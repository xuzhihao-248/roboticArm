# Dummy 机械臂完整学习大纲

> 目标：复刻原版 Dummy 机械臂 → 理解原理 → 加装 SLAM/VLA 等自定义功能
> 预算：5000元以内（不含CNC加工） | 制造方案：铝CNC + 电镀 | 减速器：国产谐波约300元/个

---

## 学习路线总览

```
第零阶段（1-2周）：前置基础补习
    ↓
第一阶段（3-5周）：硬件准备与装配
    ↓
第二阶段（2-3周）：固件烧录与调试
    ↓
第三阶段（1-2周）：上位机使用与整机联调
    ↓  ←--- 此时机械臂已经可以跑起来 ---
第四阶段（4-6周）：核心原理深度理解
    ↓
第五阶段（长期）：自定义功能扩展（视觉/SLAM/VLA）
```

## 第零阶段：前置基础补习（1-2周）

> 在动任何硬件之前，先把必要的理论知识补上。不需要精通，能看懂就行。

### 0.1 嵌入式系统入门

| 主题 | 学什么 | 学到什么程度 | 资源建议 |
|------|--------|-------------|---------|
| STM32 是什么 | 单片机概念、ARM Cortex-M 架构、STM32 产品线 | 知道 F103（电机驱动用）和 F405（核心板用）的区别 | B站搜索"STM32入门" |
| 固件是怎么跑起来的 | 交叉编译、烧录（ST-Link）、HAL 库概念 | 能把 .hex 文件烧进板子，理解 GPIO/UART/CAN 是什么 | 本项目用 STM32CubeMX 生成配置 |
| FreeRTOS 入门 | 任务（Task）、队列（Queue）、信号量 | 能读懂核心固件中的 Task 创建和调度代码 | 官方文档前3章 |

### 0.2 C/C++ 快速复习

| 主题 | 对应本项目哪里 | 说明 |
|------|--------------|------|
| 类/继承/虚函数 | `Robot/` 目录下的机械臂建模 | 本项目的固件大量使用 C++11 特性 |
| 命名空间/模板 | `UserApp/` 下的 CAN/UART 协议模板 | 作者用了 C++ 模板实现了协议抽象 |
| 指针/内存管理 | 嵌入式开发全程 | 固件中大量裸机操作，需要理解寄存器映射 |
| CMake | 项目构建 | 两个固件子项目都用 CMakeLists.txt |

### 0.3 机器人学基础概念

| 主题 | 学什么 | 说明 |
|------|--------|------|
| 关节/连杆/末端 | 机械臂的基本组成 | 本项目是6轴串联机械臂 |
| DH 参数是什么 | 四个参数描述一个关节的几何关系 | 本项目的正逆解都基于 DH 参数表 |
| 正运动学 vs 逆运动学 | 已知关节角求末端位姿（正解）、已知末端位姿求关节角（逆解） | 逆解有8组解，本项目选"最小转角"解 |
| Pieper 准则 | 三个相邻关节轴交于一点或三轴平行 | Dummy 构型满足此准则才有解析解 |

**强烈推荐书目：《机器人学导论》（John J. Craig）**

### 0.4 基础电子知识

| 主题 | 学什么 | 对应本项目哪里 |
|------|--------|--------------|

| 万用表使用 | 通断测试、电压测量、短路排查 | 焊接完成后的必备检查步骤 |

## 第一阶段：硬件准备与装配（3-5周）

### 1.1 减速器选型（关键决策）

你需要为6个关节分别选择减速器。原版用**谐波减速器**。

**选型参数：**

| 参数 | 说明 | 本项目取值参考 |
|------|------|-------------|
| 减速比 | 电机转动圈数 : 输出转动圈数 | 原版约30:1 |
| 额定扭矩 | 减速器能持续承受的扭矩 | 取决于末端负载和臂展 |
| 背隙 | 齿轮啮合间隙，越小精度越高 | 谐波减速器背隙几乎为零 |
| 输入轴/输出轴尺寸 | 与电机轴和关节结构的配合 | 需要对照 3D 模型确认 |
| 重量 | 影响整机负载和运动性能 | 越轻越好 |

**国产谐波减速器品牌参考：** 绿的谐波（Leaderdrive）、来福谐波、大族传动等。每个约 200-400 元。

**你需要做的：**
1. 打开 `4.Model/Dummy v164.step` 测量每个关节的安装空间
2. 确认电机-减速器-输出轴的机械接口尺寸
3. 根据关节位置差异选择不同型号（靠近底座的关节扭矩大，末端关节扭矩小）

### 1.2 CNC 加工与表面处理

**模型文件：** `4.Model/`
- `Dummy v164.step` — 机械臂主体结构
- `Case v17.step` — 便携手提箱
- `Motor42-上盖.step` / `Motor42-下盖.step` — 42电机外壳

**步骤：**
1. 将 STEP 文件交给 CNC 加工厂报价（注意：原版是铝合金）
2. 确认材料（推荐 6061 或 7075 铝合金）
3. 加工完成后送去阳极氧化/电镀上色
4. 检查公差配合，试组装

### 1.3 PCB 打样与元器件采购

**电路板文件（`1.Hardware/`）：**

| 电路板 | 文件 | 功能 | 数量 | 打样建议 |
|--------|------|------|------|---------|
| Controller | `Controller/` | 机械臂底座主控板 | 1块 | 4层板，1.6mm |
| MotorDriver-42 | `MotorDriver-42/` | 42步进电机闭环驱动 | 6块 | 4层板，已有Gerber |
| MotorDriver-20 | `MotorDriver-20/` | 20步进电机驱动（夹爪用） | 1块 | 4层板 |
| HandModule | `HandModule/` | 夹爪控制模块 | 1块 | - |
| LED Ring | `LedRing/` | LED灯环 | 1块 | - |
| Dangle | `Dangle/` | 无线空间定位控制器 | 1块 | 可选 |

**打样流程：**
1. 直接用 `1.Hardware/MotorDriver-42/Gerber/` 中的 Gerber 文件在线下单（推荐 JLC 嘉立创）
2. 其他板子用 `.PcbDoc` 文件导出 Gerber
3. 生成 BOM（物料清单）和 CPL（贴片坐标文件）
4. PCB 打样选择"不贴片"，拿到裸板和元器件后手工焊接

**关于 SMT 贴片：** 你选择手工焊接是正确的省钱方案。但注意：
- 板子上最密的元件是 STM32F103CBTx（LQFP48 封装），引脚间距 0.5mm，需要练习拖焊
- 电阻电容多为 0603/0805 封装，用镊子+烙铁可以操作

### 1.4 手工焊接与装配

**焊接顺序建议：**
1. 先从一块 MotorDriver-42 开始练习（你有6块，容错空间大）
2. 电源部分 → MCU → 驱动芯片 → 接口 → 电阻电容
3. 每焊完一个模块用万用表测短路
4. 全部焊完后不接电机，先上电检查电源指示灯和电压

**装配流程：**
1. 机械结构 → 减速器 → 电机 → 关节组装
2. 每个关节装好后手动转动检查顺滑度
3. 走线（CAN总线只需4根线：电源+、电源-、CAN_H、CAN_L）
4. 所有关节串联在CAN总线上
5. 安装夹爪和LED灯环

## 第二阶段：固件烧录与调试（2-3周）

### 2.1 开发环境搭建

**需要安装的软件：**

| 软件 | 用途 | 说明 |
|------|------|------|
| STM32CubeMX | 生成 STM32 初始化代码 | 免费 |
| STM32CubeIDE 或 Keil MDK | 编译固件 | CubeIDE 免费，Keil 需要 license |
| STM32 ST-LINK Utility | 烧录 .hex 文件 | 免费，用于快速烧录 |
| ST-Link 调试器（硬件） | 连接电脑和板子 | 约30元，淘宝购买 |
| USB转CAN 调试器 | 监听/发送CAN总线数据 | 调试电机驱动用，约50元 |

### 2.2 电机驱动固件（Ctrl-Step-Driver-STM32F1-fw）

**路径：** `2.Firmware/Ctrl-Step-Driver-STM32F1-fw/`

**关键文件结构：**
```
Ctrl-Step-Driver-STM32F1-fw/
├── Core/          STM32 HAL 库配置
├── Ctrl/          电机控制核心算法
├── Drivers/       CMSIS 驱动
├── Port/          硬件抽象层（GPIO/定时器/ADC）
├── UserApp/       上层应用
│   ├── interface_can.cpp    CAN总线通信协议
│   └── interface_uart.cpp   串口通信协议
└── startup/       启动文件
```

**烧录步骤：**
1. 用 ST-Link 连接电脑和电机驱动板
2. 使用 STM32 ST-LINK Utility 烧录 `2.Firmware/_Released HEX/Ctrl-Step-Driver-STM32F1-fw.hex`
3. **首次上电校准：** 电机会自动进行编码器校准（此时会有轻微抖动）
4. 如果校准失败：**同时按住按键1和按键2，再上电**，强制重新校准
5. 按按键1进入闭环模式（LED 指示灯变化确认）

**按键功能速查：**
- 短按按键1 → 使能闭环 / 取消闭环
- 长按按键1 → 重启
- 短按按键2 → 清除堵转保护
- 长按按键2 → 将目标值归零

### 2.3 核心控制器固件（Core-STM32F4-fw）

**路径：** `2.Firmware/Core-STM32F4-fw/`

**关键文件结构：**
```
Core-STM32F4-fw/
├── Core/          STM32 HAL 库
├── Drivers/       CMSIS 驱动
├── Middlewares/   FreeRTOS
├── Robot/         核心机器人库 ← 最重要的部分
│   ├── dummy_robot.cpp       DummyRobot 类的完整实现
│   ├── kinematics.cpp        正逆运动学
│   └── trajectory.cpp        轨迹规划（梯形加减速）
├── Bsp/           板载驱动（OLED/IMU/LED/蜂鸣器/EEPROM）
├── 3rdParty/     U8G2 图形库、Fibre 序列化库
├── UserApp/      上层应用入口
└── USB_DEVICE/   USB虚拟串口
```

**烧录步骤：**
1. 用 ST-Link 烧录编译好的固件
2. 初始化时配置各电机的 CAN ID、减速比、运动限制
3. 设定 DH 参数（如果结构有改动需要重新计算）

### 2.4 CAN 总线调试

这是调试阶段最重要的技能。你需要：

1. **确认每个电机的 CAN ID 不冲突**（6个电机6个不同ID）
2. **用 USB-CAN 工具监听总线**，看懂指令格式
3. **排查通信问题：**
   - 终端电阻是否正确？（CAN总线两端各一个120Ω电阻）
   - 波特率是否一致？（本项目默认 1Mbps）
   - 接线是否正确？（CAN_H 对 CAN_H，CAN_L 对 CAN_L）

- [ ] 每个电机能独立响应 CAN 指令

## 第四阶段：核心原理深度理解（4-6周）

> 机械臂跑起来之后，深入理解每个模块的原理。这是你能做二次开发的基础。

### 4.1 运动学深入

**正运动学（Forward Kinematics）：**
- DH 参数法推导末端位姿
- 齐次变换矩阵的连乘
- 用 Python 实现一遍正解（验证与固件结果一致）

**逆运动学（Inverse Kinematics）：**
- 为什么有8组解？Pieper 准则的数学含义
- 最小转角选解策略（本项目的做法）
- 用 Python 实现一遍逆解

**阅读代码：** `Core-STM32F4-fw/Robot/` 中的运动学实现

### 4.2 轨迹规划

**梯形加减速曲线：**
- 加速段 → 匀速段 → 减速段
- 如何保证6个电机同时启动同时停止？
  - 思路：计算最大关节运动角 θ_max → 根据 JointSpeed 计算总时间 → 其余电机按比例调速

**阅读代码：** `Core-STM32F4-fw/Robot/trajectory.cpp`

### 4.3 电机控制

**阅读代码：** `Ctrl-Step-Driver-STM32F1-fw/Ctrl/`

**关键概念：**
- 步进电机原理（开环 vs 闭环）
- 磁场定向控制（FOC）基础
- PID 控制三个参数的含义
- 绝对值编码器工作原理
- 电流环/速度环/位置环（三环控制）

### 4.4 通信协议

**CAN 总线协议：**
- CAN 帧格式（11位/29位 ID、数据段8字节）
- 广播帧（ID=0）用于电机同步
- 每个电机监听两个ID（自身ID + 广播ID 0）

**阅读代码：** `UserApp/interface_can.cpp`

**UART 串口协议：**
- USB虚拟串口用于与 PC 通信
- 指令格式解析

### 4.5 FreeRTOS 架构

**阅读代码：** `Core-STM32F4-fw/Middlewares/`

**关键概念：**
- 任务（Task）的创建与调度
- 队列（Queue）在不同模块间传递数据
- 定时器（Timer）用于周期任务（如轨迹插值 200Hz）
- 中断服务函数与任务的交互

## 第五阶段：自定义功能扩展（长期）

> 机械臂已经可以工作了，现在加装你想要的 SLAM 和 VLA 功能。

### 5.1 视觉感知系统

**硬件添加：**
- RGB-D 深度相机（推荐 Intel RealSense D435 或国产奥比中光，约 2000 元）
- 相机支架（需要自己设计，3D打印）

**软件任务：**
| 功能 | 技术方案 | 难度 |
|------|---------|------|
| 手眼标定 | Eye-in-hand（相机装末端）或 Eye-to-hand（相机固定）标定 | ⭐⭐ |
| 物体检测 | YOLO / OpenCV 模板匹配 | ⭐⭐ |
| 3D 位姿估计 | 点云处理（PCL/Open3D），计算物体在空间中的6D位姿 | ⭐⭐⭐ |
| 抓取规划 | 生成无碰撞的抓取姿态（GraspNet / 自定义几何分析） | ⭐⭐⭐⭐ |
| 视觉伺服 | 用视觉反馈实时调整末端运动（Visual Servoing） | ⭐⭐⭐⭐ |

### 5.2 移动底盘 + SLAM

**硬件添加：**
- 两轮差速移动底盘（推荐 TurtleBot3 方案或自己设计）
- 激光雷达（推荐思岚 RPLIDAR A1/A2，约 500-800 元）
- 工控机/Jetson Nano（约 1000 元）
- 大容量锂电池组（给机械臂+底盘供电）

**软件架构建议：**
```
工控机（ROS 2）
├── SLAM 节点（Cartographer / SLAM Toolbox）
├── 导航节点（Nav2）
├── 目标检测节点（YOLO via ONNX）
├── 抓取规划节点
└── 机械臂控制节点（通过串口/CAN与STM32通信）
```

### 5.3 VLA（Vision-Language-Action）

将自然语言指令转化为机械臂执行的物理动作。

**技术栈参考：**
| 层级 | 功能 | 技术选择 |
|------|------|---------|
| 语音/文字输入 | 将人说的话转成文本 | Whisper（语音转文字）/ 直接文字输入 |
| 任务理解 | 从自然语言提取意图和参数 | LLM（如 GPT-4o、Qwen-VL 本地部署） |
| 任务规划 | 将"抓桌上的红色方块"分解为子任务 | LLM + PDDL 规划器 |
| 技能执行 | 每个子任务对应一个可执行函数 | Python API 封装的运动原语 |

**简化版路线（推荐先做这个）：**
1. 先用 Python 封装一套机械臂控制 API（移动关节、设定位姿、开关夹爪）
2. 用 LLM API（如 OpenAI / 本地 Qwen）将自然语言翻译成 API 调用序列
3. 逐步增加视觉反馈（"抓取 XX" → 检测 XX → 计算位置 → 执行抓取）

### 5.4 可能的其他扩展方向

| 方向 | 说明 |
|------|------|
| 力控/阻抗控制 | 加装六维力传感器，实现柔顺控制（如精密装配） |
| 遥操作 | 用 Dangle 控制器或 VR 手柄远程操控 |
| 模仿学习 | 拖动机器臂示教，记录轨迹回放 |
| 双机臂协作 | 再做一台，两台协同工作 |
| Web 控制端 | 用 WebSocket 做远程控制界面 |
