> 目标：用最小成本把6块电机驱动板+1块核心板+若干模块板手工焊好

## 二、本项目的焊接难度分析

### 2.1 你需要焊的元件规格

| 元件类型 | 封装 | 难度 | 说明 |
|---------|------|------|------|
| 贴片电阻/电容 | 0603 / 0805 | ⭐ | 最基础，夹住→加锡→焊上去 |
| SOT-23 三极管/稳压器 | SOT-23 | ⭐⭐ | 3条腿，引脚间距大 |
| SOP-8 芯片 | SOP-8 | ⭐⭐ | 拖焊即可 |
| LQFP-48（STM32F103） | LQFP-48 | ⭐⭐⭐ | **最难的元件**，引脚间距0.5mm |
| QFN 芯片（驱动芯片） | QFN | ⭐⭐⭐ | 底部有散热焊盘，需要热风枪 |

### 2.2 焊接顺序建议

**先练手 → 再实战：**
1. 买一块便宜的"焊接练习板"（淘宝约10元），先练0603电阻和SOP-8
2. 用项目中的一块 MotorDriver-42 板子当"高级练习"（你有6块，可以容错）
3. 最熟练后焊 Controller 核心板（只有1块，必须一次成功）

**单板焊接顺序（按元件高度从低到高）：**
```
1. 贴片电阻电容（0603/0805）
2. SOT-23 三极管/稳压器
3. SOP-8 芯片
4. LQFP-48 MCU
5. QFN 驱动芯片
6. 直插式电容/电解电容
7. 排针/排母/接线端子
8. CAN总线接口/电源接口
```

## 三、关键元件的焊接方法

### 3.1 0805/0603 电阻电容

这是最基础的，每个板子上有几十个。方法：

```
1. 用镊子夹住元件放在焊盘上，对准位置
2. 一只手拿镊子按住元件，另一只手拿烙铁
3. 先在元件一端加锡固定（不用担心连锡）
4. 松开镊子，用烙铁和锡丝焊好另一端
5. 回到第一端，如果锡不够就补一点
6. 焊点应该圆润发亮，覆盖焊盘边缘
```

**视频搜索：** B站 "0603焊接" "贴片电阻焊接"

### 3.2 LQFP-48（STM32F103）- 拖焊法

这是本项目手工焊接最需要练习的环节。

```
准备工作：
- 刀头烙铁头（比尖头好用很多）
- 足量助焊剂（关键！越多越好）
- 0.5mm 细焊锡丝

步骤：
1. 芯片放到焊盘上，对准位置（注意1脚标记）
2. 先焊住对角两个引脚（固定芯片）
3. 用助焊剂笔在全部引脚上涂满助焊剂
4. 烙铁头上沾少量锡
5. 从一侧开始，烙铁头横着放在引脚上，缓慢拖动
6. 锡会被助焊剂引导到引脚和焊盘之间
7. 如果出现连锡：涂更多助焊剂，清洁烙铁头，再次拖动
8. 用放大镜检查每个引脚是否有虚焊或连锡
```

**关键技巧：**
- 助焊剂是你的好朋友，不要省
- 拖焊时烙铁温度：320-350°C
- 如果拖焊失败，用吸锡带吸掉重来
- 如果LQFP引脚歪了：用热风枪吹下来，吸锡带清理焊盘，重新对位

**视频搜索：** B站 "LQFP拖焊" "STM32焊接"

### 3.3 QFN 芯片 - 热风枪法

驱动板上的电机驱动芯片可能是 QFN 封装（底部有散热焊盘）。

```
1. 先在焊盘上涂薄薄一层锡浆（中温锡浆）
2. 将芯片放在焊盘上对齐（注意方向！）
3. 热风枪 280-300°C，风力调小/中
4. 先在芯片上方 3-5cm 处旋转预热（约10秒）
5. 逐渐靠近到 1-2cm，注意芯片被锡膏浸润后会自动拉正
6. QFN 自动居中后，移开热风枪
7. 冷却后用放大镜检查底部散热焊盘是否连锡
```

> 如果没有热风枪：QFN 芯片手工几乎焊不了，建议买最便宜的热风枪（约80元）

## 四、焊接后检查

### 4.1 目视检查

用放大镜逐个检查：
- [ ] 所有引脚是否有锡（无虚焊）
- [ ] 相邻引脚是否连锡
- [ ] 焊点是否圆润发亮（冷焊或虚焊会发暗/有毛刺）
- [ ] 元件是否对中、不歪斜
- [ ] 电解电容极性是否正确

### 4.2 万用表检查（通电前必做）

```
用万用表调到通断/蜂鸣挡：

1. 测电源正负极之间 → 不能短路！
2. 测3.3V输出对地 → 不能短路！
3. 测5V输出对地 → 不能短路！
4. 测每个电容两端 → 不能短路！
5. 重点测MCU的VDD和GND引脚 → 不能短路！

如果蜂鸣器响，说明短路了，不要通电！
先排查短路原因（连锡/锡珠/元件放反）
```

### 4.3 首次通电

```
1. 用带限流保护的电源供电（或串联一个电阻）
2. 先单独给电源部分上电，不接电机
3. 检查电源指示灯亮不亮
4. 用万用表测关键电压点
5. 如果板子不发烫、不冒烟 → 恭喜！
```

## 五、避免的常见错误

| 错误 | 后果 | 如何避免 |
|------|------|---------|
| 烙铁温度太高（>400°C） | 焊盘脱落，PCB损坏 | 320-350°C 已足够，含铅焊锡温度再低些 |
| 烙铁在一个地方停留太久 | 焊盘脱落 | 超过3秒焊不好 → 撤离，冷却后重新来 |
| 助焊剂太少 | 连锡、虚焊 | 涂足量助焊剂再拖焊 |
| 不看元件方向 | 芯片装反 | LQFP/QFN/SOP都有1脚标记（小圆点），对准PCB的标记 |
| 通电前不测短路 | 烧板子 | 养成通电前必测的习惯 |
| 焊完就急着上电 | 烧板子 | 等板子完全冷却，再检查一遍再上电 |

## 六、推荐的入门练习路径

```
第1天：看3个B站焊接教学视频（搜索"SMD焊接入门"）
第2天：淘宝下单焊接练习板（10-15元包邮的那种）
第3天：练习板上焊 0603×20个 + SOP-8×5个 + LQFP-48×2个
第4天：如果LQFP-48练好了 → 开始焊项目的第一块电机驱动板
第5-7天：每天焊一块板子，越来越熟练
第8-14天：焊核心板和剩下的模块板

不要着急，焊接是个手感活，越焊越熟练。
```

## 七、你可能想知道的 Q&A

**Q: 可以用低温焊锡吗？**
A: 可以，含铅焊锡（Sn63Pb37 熔点183°C）比无铅焊锡好焊。但含铅烟有毒，注意通风。无铅焊锡（Sn99.3Cu0.7 熔点227°C）更安全但温度工作要求更高。

**Q: 焊坏了怎么办？**
A: 这就是为什么先从MotorDriver-42开始——你有6块容错。如果一块实在焊坏了，吸锡带清理→热风枪拆元件→重新来过。LQFP芯片拆下来还能用。如果焊盘脱落就麻烦了，但通过飞线通常也能修好。

**Q: 代工厂只做SMT贴片贵吗？**
A: 如果只在嘉立创做PCB+SMT，仅贴片费用（不含元件）约50-100元/块板子。全部7块板子SMT打样贴片约500-800元。你的预算范围可以承受，但手工焊接是一次很好的学习经历。建议：核心Controller板做SMT（只有1块容错成本高），电机驱动板自己做手工焊接练习。
