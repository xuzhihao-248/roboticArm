# STM32F103CBT6 闭环步进电机驱动板引脚梳理

## 1. 原理图功能定位

该原理图页是闭环步进电机驱动板的主控引脚分配。主控芯片为 `STM32F103CBT6`，外围功能主要包括两相步进电机驱动、MT6816 磁编码器位置反馈、电源与温度采样、OLED 显示、USB、UART、CAN、SPI 扩展、按键以及 SWD 调试接口。

系统功能可以概括为：

```text
STM32F103CBT6
├─ 电机驱动控制
│  ├─ IN_AP / IN_AM：A 相 H 桥方向控制
│  ├─ IN_BP / IN_BM：B 相 H 桥方向控制
│  └─ IN_PWM_A / IN_PWM_B：A/B 相电流给定 PWM
│
├─ 位置反馈
│  ├─ SPI1_SCK / SPI1_MISO / SPI1_MOSI
│  ├─ MT6816_CS
│  └─ MT6816_AUX_CS
│
├─ 模拟采样
│  ├─ POWER_U：电源电压采样
│  ├─ TEMP：温度采样
│  └─ ADC_ENC：编码器或辅助模拟采样
│
├─ 人机交互
│  ├─ BUTTON_1 / BUTTON_2
│  ├─ OLED_DC
│  └─ OLED_RES
│
├─ 通信接口
│  ├─ USB_DM / USB_DP
│  ├─ UART1_TX / UART1_RX
│  ├─ CAN_RX / CAN_TX
│  └─ SPI2_SCK / SPI2_MISO / SPI2_MOSI
│
└─ 调试与启动
   ├─ SWDIO / SWCLK
   ├─ BOOT0
   ├─ NRST
   └─ 12 MHz 外部晶振
```

| STM32 引脚 | 网络名 | 当前用途 | 说明 |
|---|---|---|---|
| PA0 | `POWER_U` | 电源电压采样 | 接电源分压电路，用 ADC 采样电机驱动电源电压 |
| PA1 | `TEMP` | 温度采样 | 接热敏电阻分压，用 ADC 判断驱动板或功率器件温度 |
| PA2 | `IN_BM` | B 相反向控制 | 控制 B 相 H 桥的一个输入端 |
| PA3 | `IN_BP` | B 相正向控制 | 控制 B 相 H 桥的另一个输入端 |
| PA4 | `IN_AM` | A 相反向控制 | 控制 A 相 H 桥的一个输入端 |
| PA5 | `IN_AP` | A 相正向控制 | 控制 A 相 H 桥的另一个输入端 |
| PA6 | `ADC_ENC` | 编码器相关 ADC | 可能用于辅助编码器信号或模拟检测 |
| PA7 | `MT6816_AUX_CS` | 辅助磁编码器片选 | 若存在第二个 MT6816，可与主编码器共用 SPI1 总线 |

| PA9 | `OLED_RES` | OLED 复位 | 普通 GPIO 输出 |

| PA12 | `USB_DP` | USB D+ | STM32 USB FS 接口 |
| PA13 | `SWDIO` | SWD 调试数据 | 下载与在线调试接口，建议保留 |
| PA14 | `SWCLK` | SWD 调试时钟 | 下载与在线调试接口，建议保留 |
| PA15 | `MT6816_CS` | 主磁编码器片选 | SPI1 主编码器 CS 信号 |

## 4. 电机驱动控制接口

该设计用于两相步进电机驱动。结合 TB67H450FNG H 桥驱动芯片，STM32 对电机的控制分为两部分：方向控制与电流幅值控制。

### 4.1 方向控制信号

| 控制信号 | STM32 引脚 | 控制对象 | 作用 |
|---|---|---|---|
| `IN_AP` | PA5 | A 相 | A 相正向输入 |
| `IN_AM` | PA4 | A 相 | A 相反向输入 |
| `IN_BP` | PA3 | B 相 | B 相正向输入 |
| `IN_BM` | PA2 | B 相 | B 相反向输入 |

方向控制逻辑可以理解为：

```text
PA5 / PA4 → 控制 A 相电流方向
PA3 / PA2 → 控制 B 相电流方向
```

A 相正反向由 `IN_AP` 和 `IN_AM` 决定，B 相正反向由 `IN_BP` 和 `IN_BM` 决定。具体输入真值表需要以 TB67H450FNG 数据手册为准。

### 4.2 电流给定 PWM 信号

| 控制信号 | STM32 引脚 | 控制对象 | 作用 |
|---|---|---|---|
| `IN_PWM_A` | PB11 | A 相 | A 相电流给定 PWM |
| `IN_PWM_B` | PB10 | B 相 | B 相电流给定 PWM |

这两路 PWM 经过外部 RC 低通滤波后，分别形成：

```text
IN_PWM_A → RC 滤波 → VREF_A
IN_PWM_B → RC 滤波 → VREF_B
```

`VREF_A` 和 `VREF_B` 接入 TB67H450FNG 的 `VREF` 引脚，用于设定 A/B 相限流参考值。因此：

```text
PWM 占空比越大 → VREF 越高 → 目标相电流越大
PWM 占空比越小 → VREF 越低 → 目标相电流越小
```

在细分步进控制中，软件可以按照正弦规律更新两路 PWM：

```text
VREF_A ∝ |sin θ|
VREF_B ∝ |cos θ|
```

方向由 `IN_AP/IN_AM`、`IN_BP/IN_BM` 决定，幅值由 `IN_PWM_A/IN_PWM_B` 决定。

## 5. MT6816 磁编码器接口

MT6816 通过 SPI1 与 STM32 通信，用于读取电机转子角度。

| 信号 | STM32 引脚 | 说明 |
|---|---|---|
| `SPI1_SCK` | PB3 | SPI1 时钟 |
| `SPI1_MISO` | PB4 | 编码器数据输出到 MCU |
| `SPI1_MOSI` | PB5 | MCU 发命令给编码器 |
| `MT6816_CS` | PA15 | 主磁编码器片选 |
| `MT6816_AUX_CS` | PA7 | 辅助磁编码器片选 |

该设计预留了两个片选信号，说明可以支持两个 MT6816 共用同一组 SPI1 总线：

```text
SPI1_SCK / SPI1_MISO / SPI1_MOSI 共享
PA15 → 主编码器 CS
PA7  → 辅助编码器 CS
```

实际读取时，每次只拉低一个 CS，另一个 CS 保持高电平，避免两个 SPI 从设备同时驱动 MISO 总线。

## 6. 模拟采样接口

| 信号 | STM32 引脚 | ADC 通道 | 用途 |
|---|---|---|---|
| `POWER_U` | PA0 | ADC1_IN0 | 采样电机驱动电源电压 |
| `TEMP` | PA1 | ADC1_IN1 | 采样温度检测电压 |
| `ADC_ENC` | PA6 | ADC1_IN6 | 编码器或辅助模拟信号采样 |

### 6.1 POWER_U

`POWER_U` 通常来自电机驱动电源的电阻分压网络。STM32 通过 ADC 读取该节点电压，再根据分压比换算实际电源电压。该信号可用于欠压、过压保护。

### 6.2 TEMP

`TEMP` 通常来自热敏电阻分压网络。STM32 通过 ADC 读取该节点电压，根据热敏电阻参数换算温度。该信号可用于过温降流或过温停机保护。

### 6.3 ADC_ENC

`ADC_ENC` 的具体功能需要结合其他原理图页确认。从命名看，它可能与编码器辅助信号、磁场强度检测或其他模拟检测有关。

## 7. 通信接口

### 7.1 USB 接口

| 信号 | STM32 引脚 | 说明 |
|---|---|---|
| `USB_DM` | PA11 | USB D- |
| `USB_DP` | PA12 | USB D+ |

STM32F103 的 USB FS 接口使用 PA11/PA12。若使用 USB，系统时钟需要提供准确的 48 MHz USB 时钟。

### 7.2 UART1 接口

| 信号 | STM32 引脚 | 说明 |
|---|---|---|
| `UART1_TX` | PB6 | USART1 发送 |
| `UART1_RX` | PB7 | USART1 接收 |

USART1 默认引脚不是 PB6/PB7，因此这里需要使用 USART1 重映射。

### 7.3 CAN 接口

| 信号 | STM32 引脚 | 说明 |
|---|---|---|
| `CAN_RX` | PB8 | CAN 接收 |
| `CAN_TX` | PB9 | CAN 发送 |

CAN 默认引脚不是 PB8/PB9，因此这里需要使用 CAN 重映射。需要注意，PB8/PB9 是 MCU 逻辑电平信号，外部还需要 CAN 收发器才能连接 CANH/CANL 总线。

### 7.4 SPI2 接口

| 信号 | STM32 引脚 | 说明 |
|---|---|---|
| `SPI2_SCK` | PB13 | SPI2 时钟 |
| `SPI2_MISO` | PB14 | SPI2 输入 |
| `SPI2_MOSI` | PB15 | SPI2 输出 |

SPI2 可用于 OLED、外部 Flash、外部传感器或扩展接口，具体连接需要结合其他原理图页确认。

### 8.1 OLED 控制信号

这两个信号为普通 GPIO 输出。OLED 的 SPI 数据线可能使用 SPI2，也可能通过其他原理图页连接。

### 8.2 按键信号

|---|---|---|
| `BUTTON_1` | PB12 | 普通按键输入 |

## 9. 调试、启动与时钟

### 9.1 SWD 调试接口

| 信号 | STM32 引脚 | 说明 |
|---|---|---|
| `SWDIO` | PA13 | SWD 数据 |
| `SWCLK` | PA14 | SWD 时钟 |

PA13/PA14 保留为 SWD 下载和在线调试接口。

### 9.2 BOOT0 与启动模式

`BOOT0` 通过 10 kΩ 电阻下拉到 GND，因此芯片默认从主 Flash 启动。

```text
BOOT0 = 0 → 从主 Flash 启动
```

PB2 同时具有 BOOT1 功能。由于 BOOT0 已经固定下拉，正常启动时 PB2 对启动模式影响较小，但仍需避免上电瞬间被异常拉动。

### 9.3 NRST 复位电路

`NRST` 由 10 kΩ 电阻上拉到 `VCC_3V3`，并通过 0.1 µF 电容接地，形成 RC 复位电路。

```text
VCC_3V3 ─ 10kΩ ─ NRST
NRST ─ 0.1µF ─ GND
```

该电路可以在上电时产生短暂复位，保证 MCU 稳定启动。

### 9.4 12 MHz 外部晶振

外部晶振 Y1 接在：

```text
PD0-OSC_IN
PD1-OSC_OUT
```

若 HSE 为 12 MHz，可以通过 PLL 倍频得到 72 MHz 系统时钟，并为 USB 提供 48 MHz 时钟。

## 10. 关键复用与配置注意事项

### 10.1 关闭 JTAG，保留 SWD

PB3、PB4、PA15 默认与 JTAG 相关，而本设计中它们分别用于：

```text
PB3  → SPI1_SCK
PB4  → SPI1_MISO
PA15 → MT6816_CS
```

因此，程序初始化时需要关闭 JTAG，但保留 SWD。否则 MT6816 的 SPI 通信可能异常。

### 10.2 SPI1 重映射

SPI1 默认引脚通常为 PA5/PA6/PA7，但本设计中 SPI1 使用：

```text
PB3 → SPI1_SCK
PB4 → SPI1_MISO
PB5 → SPI1_MOSI
```

因此需要开启 SPI1 重映射。

### 10.3 USART1 重映射

USART1 使用：

```text
PB6 → USART1_TX
PB7 → USART1_RX
```

因此需要开启 USART1 重映射。

### 10.4 CAN 重映射

CAN 使用：

```text
PB8 → CAN_RX
PB9 → CAN_TX
```

因此需要开启 CAN 重映射。

### 10.5 PWM 定时器配置

建议使用硬件定时器输出两路 PWM：

```text
PB10 → IN_PWM_B
PB11 → IN_PWM_A
```

两路 PWM 最好来自同一个定时器，以保证 A/B 相电流给定更新同步。

下面给出一个面向该原理图的初始化配置思路，实际配置需结合工程代码和 CubeMX 工程确认。

```text
SYS:
  Debug = Serial Wire
  Disable JTAG, keep SWD

RCC:
  HSE = Crystal/Ceramic Resonator
  HSE frequency = 12 MHz
  SYSCLK = 72 MHz
  USBCLK = 48 MHz

ADC1:
  PA0 / ADC1_IN0 = POWER_U
  PA1 / ADC1_IN1 = TEMP
  PA6 / ADC1_IN6 = ADC_ENC

  Remap to PB3/PB4/PB5
  PA15 = MT6816_CS, GPIO Output, default High
  PA7  = MT6816_AUX_CS, GPIO Output, default High

USART1:
  Remap to PB6/PB7

CAN:
  Remap to PB8/PB9

PWM:
  PB10 = IN_PWM_B
  PB11 = IN_PWM_A

GPIO Output:
  PA2 = IN_BM
  PA3 = IN_BP
  PA4 = IN_AM
  PA5 = IN_AP
  PA8 = OLED_DC
  PA9 = OLED_RES

GPIO Input:
  PB12 = BUTTON_1
  PB2  = BUTTON_2
```

## 12. 总结

该 STM32F103CBT6 引脚分配适合用于闭环 42 步进电机驱动板。整体设计逻辑为：

```text
STM32 输出方向控制信号和 PWM 电流给定
       ↓
TB67H450FNG 控制 A/B 两相绕组电流
       ↓
MT6816 读取电机轴角度
       ↓
STM32 根据角度反馈实现闭环位置/速度控制
```

这套引脚分配的核心注意点有四个：

1. `PB3/PB4/PA15` 与 JTAG 功能冲突，必须关闭 JTAG 并保留 SWD。
2. `SPI1`、`USART1`、`CAN` 均涉及重映射，固件初始化必须正确配置。
3. `PB10/PB11` 建议使用硬件 PWM，用于稳定生成 A/B 相电流给定。
4. `POWER_U`、`TEMP`、`ADC_ENC` 应配置为模拟输入，并结合分压比或传感器参数完成实际物理量换算。
